# Programación III - Módulo 5

## Taller grupal: Listas, diccionarios y condicionales

En este repositorio estaremos trabajando en la actividad grupal del módulo 5 de Programación III.

La idea es crear un programa sencillo en Python que permita buscar la edad de una persona a partir de su nombre.

Para esto utilizamos una lista de nombres, un diccionario con las edades y condicionales para comprobar si la persona ingresada se encuentra registrada.

## ¿Cómo funciona?

El programa le solicita al usuario que escriba un nombre.

Si ese nombre está en el diccionario, se muestra la edad correspondiente. Si no está, se indica que la persona no fue encontrada.

## ¿Cómo ejecutarlo?

Desde la terminal:

`python edades.py`
